# 24点卡牌游戏

卡牌风格的 24 点计算游戏（Vue 3 + Vite，纯前端，无后端）。

## 运行

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（默认 http://localhost:5173）
npm run build      # 生产构建，产物输出到 dist/
npm run preview    # 预览生产构建
npm test           # 运行单元测试（Vitest）
```

## 玩法（阶段一）

- 系统随机发 4 张数字卡（1–10），保证本局可解出目标 24。
- 点击卡牌把数字放入草稿纸数字槽；点击下方运算符面板填入 `+ − × ÷`。
- 用数字槽两侧的 `( )` 小按钮插入括号，系统自动校验括号配对。
- 填满后点击「提交」：等于 24 则得分 +1 并自动发下一副牌；算错则算式抖动、红叉提示。
- 「提示」只揭示第一步线索；「换牌」可跳过当前这副牌；「↶ / 🧽」单步撤销 / 一键清空；「重开」重置得分与计时。

## 技术要点

- `src/core/solver.js`：子集 DP + 有理数（分数）四则运算求解器，支持任意目标值（24/36/48/随机），用于可解校验与提示生成。
- `src/core/expression.js`：槽位表达式模型（4 数字 + 3 运算符 + 括号），递归下降求值，除零/括号不匹配安全处理。
- `src/composables/useGame.js`：游戏状态机（发牌/填槽/提交/提示/换牌/撤销/计时），组件间 provide/inject。
- 木炭手绘风：宣纸底 + SVG `feTurbulence/feDisplacementMap` 毛躁边缘滤镜。
