# 24点卡牌游戏

卡牌风格的 24 点计算游戏（Vue 3 + Vite，纯前端，无后端）。木质桌面背景，**拖拽合成**玩法。

## 运行

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（默认 http://localhost:5173）
npm run build      # 生产构建，产物输出到 dist/
npm run preview    # 预览生产构建
npm test           # 运行单元测试（Vitest）
```

## 玩法

- 系统随机发 4 张数字卡（1–10），保证本局可解出目标 24。
- **拖拽合成**：把一张卡拖到另一张卡上 → 弹出运算选择器（`A+B`、`A−B`、`B−A`、`A×B`、`A÷B`、`B÷A`，显示真实数值预览）→ 两张卡合并为一张合成卡（允许分数，如 `8/3`）。
- 合成卡可继续与其它卡拖拽合并，4 张牌最终合成 1 张。
- **自动结算**：合成到只剩 1 张时立即判定——等于 24 则得分 +1 并自动发下一副；不等于 24 则提示结果，可撤销重试。
- 「撤销」可逐步回退合并；「提示」给出第一步合并建议（如"先用 8 和 3 除，得到 8/3"）；「换牌」跳过本局；「重开」重置得分与计时。

## 技术要点

- `src/core/rational.js`：有理数（分数）四则运算，避免浮点误差。
- `src/core/merge.js`：拖拽合成核心——`combine` 合并两张卡、`isSolved` 结算判定、`formatTree` 表达式树格式化。
- `src/core/solver.js`：子集 DP 求解器，支持任意目标值（24/36/48/随机），用于发牌可解校验与提示生成。
- `src/composables/useGame.js`：游戏状态机（发牌/拖拽/合并/撤销/自动结算/计分计时），组件间 provide/inject。
- 拖拽用 **Pointer Events** 实现（鼠标 + 触屏统一），`CardTable` 统一管理命中检测与幽灵卡。
- 视觉：木质桌面（CSS 木纹渐变 + feTurbulence 噪点）+ 炭笔/宣纸卡面。
